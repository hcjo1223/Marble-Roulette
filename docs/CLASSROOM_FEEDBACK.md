# 🏫 수업 실사용 피드백 수집 및 다음 단계 반영 기록

태권도장 · 학급 · 방과후 수업 현장에서 **총총 래그돌 달리기 3D (Marble-Roulette)** 를 실제 운영한 뒤 학생 반응, 기기 성능, 개선 아이디어를 기록하기 위한 템플릿입니다.

---

## 📋 1. 앱 내 1클릭 로그 수집 방법

1. 레이스 완주 후 결과 모달 하단의 **`📝 수업 기록 복사`** 버튼을 누릅니다.
2. 아래 항목이 클립보드에 자동 생성됩니다:
   - 일시 / 선택한 맵 테마 / 참가자 수 / 당첨 방식
   - 최종 당첨자 이름 · 완주 시간 · 래그돌 피격 횟수
   - (프레임 측정 `📊` 켜짐 시) 실측 평균 FPS · 평균 프레임 시간 · p95 · 물리 `worldStep` 시간
3. 복사한 내용을 아래 세션 로그 표에 붙여넣고 학생 반응 및 개선 포인트를 메모합니다.

## 🔍 3. 핵심 체크리스트 (현장 점검용)

- [ ] **가시성/가독성**: 대형 TV · 빔프로젝터 · 태블릿 화면에서 선두 순위표와 캐릭터 이름표가 한눈에 들어오는지
- [ ] **음향/분위기**: 시작 호각, 관중 환호, 맵별 BGM 음량이 수업 안내 멘트와 겹치지 않는지 (`🔇`/`🎵` 토글 편의성)
- [ ] **기기 발열/프레임**: 저사양 안드로이드 폰/태블릿에서 48명 동시 출발 시 프레임 드랍·터치 지연이 없는지 (`📊 프레임 측정` 활용)
- [ ] **공정성 & 역전감**: 1등/꼴찌/N등 규칙별 변별력과 결승 직전 기믹(`2명`/`4명`/`끔`) 밸런스가 적절한지
- [ ] **재경기 회전율**: 결과 모달 **`🔄 같은 멤버로 즉시 재경기`** 또는 **`📸 공유 카드 저장`** 후 다음 게임 전환이 빠른지

## 🚀 4. 다음 단계 백로그 반영 기준

1. **즉시 수정 (P0)**: 수업 진행이 막히는 버그, 이름표 겹침, 사운드 끊김, 모바일 UI 터치 오작동
2. **밸런스 패치 (P1)**: 특정 맵 구간(예: 수영장 파도 밀림 세기, 튜브 지속시간, 공룡 카트 부스터) 난이도 튜닝
3. **신규 콘텐츠 (P2)**: 현장 요청 장애물 추가, 커스텀 맵 프리셋 확장, 학급/도장 전용 공유 카드 문구 커스터마이징
