# 🏃‍♂️💥 Ragdoll Derby 3D (래그돌 더비 3D)

**Three.js + Rapier3D(WebAssembly) 기반 로블록스풍(R6) 3D 블록 캐릭터 액티브 래그돌 장애물 레이스 추첨기**

설치 없이 웹 브라우저 URL 공유만으로 최대 48명의 참가자가 R6 블록형 3D 캐릭터가 되어 회전 망치, 바닥 팝업 범퍼, 강풍 선풍기, 컨베이어 벨트, 병목 진자 해머 코스를 돌파하며 당첨자(1등 / 꼴찌 / N등)를 가리는 3D 파티 내기 게임입니다.

## ✨ 핵심 구현 요소

1. **R6 블록형 3D 캐릭터 & 관절 기반 액티브 래그돌(Active Ragdoll) 물리**
   - `Head`, `Torso`, `LeftArm`, `RightArm`, `LeftLeg`, `RightLeg` 6개의 독립 강체(`RigidBody`)와 5개의 물리 관절(`SphericalImpulseJoint`, `RevoluteImpulseJoint`)로 결합된 R6 캐릭터
   - 캐릭터 상단에 실시간 순위 배지(`#1`)와 참가자 닉네임, 피격/당첨 상태 아이콘을 표시하는 3D 빌보드 UI(`THREE.Sprite`)
   - 평상시에는 직립 자세로 팔다리를 교차 스윙하며 달리고(`RUNNING`), 장애물 타격 시 직립 토크와 관절 모터 강성이 해제되어 사지가 꺾이고 공중제비를 돌며 굴러떨어지는(`RAGDOLL`) 리얼 래그돌 연출

2. **자율 주행(Steering) & 무작위성(Randomness) 혼합 AI**
   - 결승선 방향(`+Z` 하강 경사) 추진력 + 개체별 고유 주파수/위상 기반 좌우 사행(Sinusoidal Lateral Wander)
   - 무작위 점프 타이밍 편차 및 하위권 탄력 가속(Rubber-banding)으로 매 판 예측 불가한 순위 변동 생성
   - 트랙 이탈 시 자동 체크포인트 리스폰 및 병목 끼임 시 긴급 점프 탈출

3. **5단계 역전 장애물 기믹 (140m 코스)**
   - **Zone 1 (회전 망치 / 스위퍼)**: 반대 방향으로 고속 회전하며 캐릭터를 후려쳐 날려버리는 대형 해머 바
   - **Zone 2 (바닥 팝업 범퍼 & 핀볼 기둥)**: 바닥에서 주기적으로 솟구쳐 캐릭터를 공중으로 쏘아 올리는 스프링 피스톤과 고탄성 핀볼 범퍼
   - **Zone 3 (밀어내는 선풍기 강풍 & 컨베이어 벨트)**: 측면 초대형 터빈 선풍기의 횡풍 물리 구역과 가속(`>>>`)/역방향(`<<<`) 컨베이어 벨트
   - **Zone 4 (좁아지는 병목 구간 & 진자 해머)**: 트랙 폭이 급격히 좁아지는 깔때기 다리와 공중에서 스윙하는 대형 진자 해머
   - **Zone 5 (최종 역전 슬로프 & 결승선)**: 피니시 라인 직전 마지막 듀얼 스위퍼와 체크무늬 결승선 아치

4. **관전용 멀티 카메라 & 결승선 직전 슬로우 모션 연출**
   - `🎥 선두 그룹 카메라 (1)`: 실시간 선두권 그룹을 부드럽게 오토 팔로우
   - `🐢 꼴찌 카메라 (2)`: 최하위 참가자 밀착 추적 (벌칙 내기 최적화)
   - `🗺️ 전체 탑뷰 (3)`: 코스 전체 흐름을 조망하는 하이앵글 전술 카메라 (마우스 드래그로 코스 상하 이동)
   - `🕹️ 자유/개인 포커스 (4)`: 우측 실시간 순위표에서 원하는 참가자 클릭 시 해당 캐릭터 단독 마크 + 마우스 회전/줌
   - `🎬 클라이맥스 슬로우 모션`: 당첨 결정 순위 참가자가 결승선 전방 `11.5m` 진입 시 자동으로 `0.22x` 슬로우 모션 + 시네마틱 줌인 + 레터박스 연출 발동 (`Space` 키로 수동 토글 가능)

## ✨ 최근 추가 · 개선된 기능

- **수영장 2단계 기믹**: 물놀이 튜브 탑승 패드(`🛟`), 3D 파도 존 물살 밀림 & 대형 롤링 웨이브, 주기적 물대포 워터젯
- **3D 맵 에디터 (`/ ?custom=`)**: 상단 `🛠️ 에디터` 버튼으로 11종의 장애물을 트랙에 직접 배치·미세조정(`Z`/`X`/방향/크기)하고 JSON 또는 URL 링크로 저장/공유
- **폴가이즈 테마 결과 공유 카드**: 완주 즉시 결승선 3D 스크린샷과 우승자·포디움 정보를 담은 `1080×1350` PNG 카드 생성 및 저장/복사/공유
- **사운드 & 관중 연출 확장**: 5개 맵 전용 멀티채널 BGM + 시작 호각·물보라·튜브 탑승·관중 환호/탄식 Web Audio 효과음 + `InstancedMesh` 경기장 관중석 애니메이션
- **모바일 48인 물리·렌더링 최적화 & 프레임 측정기**: `lowCost` LOD 파이프라인, GPU 인스턴싱, `@dimforge/rapier3d` 외부 스트리밍 WASM 청크 분리 (`?perf=1` 또는 `📊 프레임 측정`)

## 🚀 실행 및 CI/CD 배포 파이프라인 (`feature/*` → `gh-page` → `main`)

```bash
npm install
npm run dev       # 로컬 개발 서버
npm run build     # TypeScript 검사 + Vite 프로덕션 번들 (dist/ 생성)
```

| 단계 | 브랜치 | 직접 Push | 역할 및 자동 배포 대상 |
| --- | --- | :---: | --- |
| **1. 개발** | `feature/*` | ✅ 허용 | 기능 개발 및 CI 빌드(`tsc && vite build`) 검증 → 완료 후 `gh-page`로 PR 생성 |
| **2. 검증 (Staging)** | `gh-page` | ❌ 금지 (PR 필수) | PR 병합 시 GitHub Actions([`.github/workflows/ci.yml`](./.github/workflows/ci.yml))가 **GitHub Pages 검증용 화면**(`https://hcjo1223.github.io/Marble-Roulette/`)에 자동 배포 |
| **3. 운영 (Production)** | `main` | ❌ 금지 (`gh-page` PR만 허용) | `gh-page → main` PR 병합 시 **Vercel 운영 화면**([`vercel.json`](./vercel.json))으로 자동 배포 (`feature/* → main` 직행 PR은 CI가 자동 차단) |

- 수업 현장 피드백 기록 및 다음 단계 반영은 [docs/CLASSROOM_FEEDBACK.md](./docs/CLASSROOM_FEEDBACK.md), 상세 기획 문서는 [docs/PLAN_AND_DESIGN.md](./docs/PLAN_AND_DESIGN.md)에서 확인할 수 있습니다.
